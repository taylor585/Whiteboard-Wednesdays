# Worked example: ICP Buyer Research (Pecuna Factorem, October 2026)

The full packaging run for one real video, from the brief to what was published. Use it as the model answer for a Package request.

| File | What it is |
|---|---|
| `brief.md` | Taylor's brief, verbatim |
| `batch.json` | the original draft batch run through `scripts/package.py`: 10 titles, 5 round-1 thumbnail specs, description, 3 LinkedIn posts. It still has `[PLACEHOLDER]` links, which the packager lists as NOTE lines. The published description is `description-final.txt`. |
| `titles-scored.md` | the 10 titles with scores; recommended vs published |
| `thumbnails/round1-concepts/` | the 5 first concepts (face placeholder) |
| `thumbnails/round2-light/` | object-only scenes A–C, plus LinkedIn sizes of the light version |
| `thumbnails/round3-dark/` | D1–D3, the "make it pop" round |
| `thumbnails/final/` | the D1 Spotlight files that were posted (YouTube, LinkedIn video cover, LinkedIn 4:5) |
| `description-final.txt` | the description in house style, as published |
| `linkedin-posts.md` | 3 LinkedIn posts |
| `decisions.md` | every decision, who made it and why |

Specs for the scenes: `examples/read-their-mind.json` (round 2), `examples/read-their-mind-dark.json` (round 3) and `examples/read-their-mind-final.json` (the finals).
