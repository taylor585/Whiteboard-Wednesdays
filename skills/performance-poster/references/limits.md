# Limits at a glance

`limits.json` is the source of truth: `check_post.py` and the tests read it. This page is the readable summary. Checked 20 Oct 2026; re-check by 18 Jan 2027.

| | YouTube | LinkedIn | Instagram |
|---|---|---|---|
| Hard maximum | Description 5,000 bytes · title 100 (house ≤70) · tags field 500 | Post 3,000 · comment 1,250 | Caption 2,200 incl. hashtags · 20 @mentions |
| Before the fold | ~150 characters; keyword in the hook's first 40 (the CTA line takes 108) | Hook ≤140, ideally ≤110 | First line ≤60 (Reels) · ≤125 (feed) |
| Optimal length | ~800–2,000, never padded | 900–1,500 reach · 1,500–2,500 comments | Reels 125–500 · carousels <30 words · images 300–800 |
| Hashtags | 3 (house allows 3–5; only 3 show; >60 = all ignored) | 3 (house 3–5; research 1–2, max 3) | 3–5, hard cap 5, in the caption |
| Structure | Exact CTA line 1; chapters 0:00, ≥3, ≥10 s; blank line between every bullet and chapter; disclosure for affiliate links | No link in the body; one question; no bait | One CTA, matching the end card; alt text on images; safe zones 220 px top, 420 px bottom |
| Truth (all) | Every figure in the brief or transcript · no client names · placeholders listed | | |

Sources and confidence for each row: `youtube.md`, `linkedin.md`, `instagram.md`, and the Performance Poster research report (`research/performance-poster/Performance-Poster-Research.pdf` in the Whiteboard Wednesdays repo).
