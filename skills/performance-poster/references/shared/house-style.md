# House style: Pecuna Factorem (Taylor Cunningham)

Apply this to every YouTube description, LinkedIn post and call to action written for Pecuna Factorem. It overrides the defaults in `references/frameworks/description-framework.md` and `references/frameworks/linkedin-framework.md` where they differ. Saved at Taylor's request on 13 October 2026.

## Calls to action

- **Pinned CTA, always line 1 of a YouTube description** (copy exactly, with one space after the arrow):

  ```
  Want to chat? Give me a message on WhatsApp. This is my personal number 👉 https://pecunafactorem.com/contact
  ```
- A blank line follows it, then the hook.
- Other approved CTAs: `assets/cta/Pecuna-Factorem-CTA-Library.pdf` (source: `assets/cta/cta-library.html`). Add new ones to the top of that list with the date and the video they were first used on.
- Closing block links to the same contact page: "…get in touch: https://pecunafactorem.com/contact". Website line: "Pecuna Factorem: https://pecunafactorem.com".
- Always put a space between an emoji or arrow and the link that follows it.

## Layout: well spaced, easy to scan

- A blank line between **every** item in "What you'll learn" (each bullet on its own, with space around it).
- A blank line between **every** chapter line. YouTube still reads the timestamps, as long as each line starts with the time and the first is 0:00.
- A blank line between each paragraph of "How we can help".
- A blank line between sections (CTA, hook, summary, What you'll learn, Chapters, How we can help, links, hashtags).
- Section headings on their own line: `What you'll learn:`, `Chapters`, `How we can help`.
- Deliver the finished description in one copy-and-paste text box, with no placeholders left when the real link is known.

## Copy rules (from the original brief)

- UK English. Never name a client; say "a med spa client".
- Only figures said in the video; never invent results.
- 3–5 hashtags (the brand rule; this overrides the 0–3 default).
- Titles of 70 characters or fewer (the brief said "under 70"; 70 is the hard limit), with the hook in the first 40.

## Delivery preferences (how Taylor likes work handed over)

- **Save every finished thumbnail to Google Drive** (Taylor's standing rule, 17 Oct 2026). Use the folder https://drive.google.com/drive/u/0/folders/1EajLSFKTefiFUvEzVNuSZoKQjwhbS4cI:
  - YouTube files go in the `YouTube` subfolder; LinkedIn files go in the `LinkedIn` subfolder.
  - Name each file with the video's title: `<Title>.jpg` for YouTube; `<Title> (LinkedIn video cover 1920x1080).jpg` and `<Title> (LinkedIn image post 1080x1350).jpg` for LinkedIn.
  - Use the Google Drive connector, and confirm each upload's size matches the local file.

- **Simple asks get the files straight away.** "Give me the YouTube and LinkedIn versions" means send the finished files now, with no plan. Taylor rejected a plan for a simple re-send.
- **Label every file with its platform and size** in the name and the caption, e.g. `YouTube-thumbnail-1280x720.jpg`, `LinkedIn-video-cover-1920x1080.jpg`, `LinkedIn-image-post-1080x1350.jpg`. Say which LinkedIn file to use for which kind of post.
- **Explain any teaser chip** (e.g. "NEW VIDEO · 39 MIN" appears only on the LinkedIn image teaser; 39 min is the running time).
- **Copy-and-paste text goes in one text box,** ready to paste, with no placeholders left when the real link is known (the contact link is https://pecunafactorem.com/contact).
- **When asked "what did we choose",** give the exact chosen text first, then how to change it (YouTube Studio → Content → Details → Title).
- **Say plainly when something is a guess, untested or from a third-party source** (platform sizes, LinkedIn rules).
- **Don't ask questions the conversation already answers** (e.g. which repo the app is in).
