# Performance Poster research

The research behind the planned Performance Poster skill. It covers YouTube descriptions, LinkedIn posts and Instagram captions: character limits, hashtags, and how the skill will build each one.

- `Performance-Poster-Research.pdf`: the finished report, in sections for YouTube, LinkedIn and Instagram (in progress).
- `fonts/`: the brand fonts used to render the PDF, each with its licence.

This folder isn't part of the public site build (`dist/`).
