17 / 03 / Why it works

Fresh eyes

Reason 5 · Claude Code docs
“A fresh reviewer does help, because it hasn't seen your reasoning, which is a different thing from delegating.”
Models correct a mistake well once told where it is, but find their own badly: the best scored 52.87 at finding them (GPT-4). A feedback round added about 20% on average.
Claude Code docs, “Best practices for Claude Code”, read 13 November 2026, word for word. 52.87: Tyen et al., “LLMs cannot find reasoning errors, but can correct them given the error location”, 2023, page 4. About 20%: Madaan et al., “Self-Refine”, NeurIPS 2023, page 1.
